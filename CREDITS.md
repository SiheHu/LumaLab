## AI assistance, Skills and research tools

- **OpenAI Codex** assisted with design, Swift / C / C++ implementation, tests, documentation and local UI checks. Development used GPT-6-family assistance in this conversation; a complete per-turn model/version log was not archived, so this project does not invent a single exact model ID for all historical work. No OpenAI model or API is required by the editor at runtime.
- **`reverse-engineer-anything` Skill**, from [morluto/rea](https://github.com/morluto/rea), and the **REA MCP Server** (historical research records identify 6.5.0), guided investigation of installed app behavior, packaged features and selected native routines. The locally installed Skill declares version 42. REA's upstream MIT license applies to its own code; it does not license the software being examined. The Skill / MCP Server is not bundled or required to build LumaLab.
- **Hopper Disassembler / its REA Bridge** was a development research tool for native analysis. It is proprietary software, not an open-source dependency, and is not redistributed.
- **Codex app tools, Computer Use / CUA, GitHub integration, Python, SwiftPM and Xcode Command Line Tools** supported builds, file work and verification. They are development tooling, not extra runtime libraries.
- **Pillow and sharp** supported local fixture inspection and rendering of the original SVG documentation illustration. They are development-only tools and are not bundled with the app or required to build it.
- Available Skills are not the same as Skills actually applied. The project history confirms REA usage; this credits file does not claim that every installed Skill was used. The built-in Demo and icon are generated by the checked-in drawing code, not downloaded photographs or an AI image model.

## Implementation and publication boundary

Camera Raw / Lightroom were feature and behavior references; limited read-only native analysis informed research and numerical experiments. This was **not a formal clean-room process**, and the project does not claim access to Adobe source or a complete reconstruction of Adobe algorithms. Proprietary binaries, decompiled listings, research dumps, original test photographs and session backups are excluded from this public source publication. Publicly licensed Adobe DNG SDK fragments remain inside upstream LibRaw with their original notices.

LumaLab is not affiliated with Adobe, Apple, Microsoft, Google or the model publishers. It does not use Firefly, cloud Generative Remove, OpenCV or SciPy at runtime, and does not promise Camera Raw performance or identical pixels.
